# PY03 · Resilient file reader

Create `main.py` with a `read_text_safely(path)` function. Read a UTF-8 text file and handle a missing file explicitly. Do not hide every exception without explanation.

Test an existing text file, an empty file and a path that does not exist. Explain how callers distinguish successful reads from errors in your own `README.md` (at least 40 words). The dashboard checks valid Python, the named non-stub function, a try statement inside it, and your explanation. Those structural checks do not execute these tests.
