# PY02 · Expense summary

Create `main.py` with a `summarize_expenses(expenses)` function that returns a summary including the total. Choose and document a representation for each expense. Keep calculations separate from printing.

Test an empty list, one expense and several expenses. Explain whether negative amounts are valid and why in your own `README.md` (at least 40 words). The dashboard checks valid Python, the named non-stub function, a return statement inside it, and your explanation. Those structural checks do not execute these tests.
