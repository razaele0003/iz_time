# Temperature Converter

This project converts Celsius temperatures into Fahrenheit using the
formula Celsius multiplied by nine fifths, plus thirty-two. The reusable
function accepts a number and returns the converted value. User input
and printing are handled separately. Invalid text input displays a
helpful message instead of crashing. Negative temperatures and decimal
values are supported.

Suggested checks: 0°C should produce 32°F, 100°C should produce 212°F,
and -40°C should produce -40°F.

Assistance: This initial solution was provided by ChatGPT.
