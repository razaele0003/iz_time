# Ohm's Law Calculator

This project calculates electrical current using Ohm's Law.

The user provides the voltage and resistance. The program calculates current
using the formula I = V / R and displays the result clearly.

For example, when the voltage is 12 volts and the resistance is 4 ohms,
the calculated current is 3 amps.

## Formula

I = V / R

Where:

- I = current in amps
- V = voltage in volts
- R = resistance in ohms

## Test

Input:
12 V
4 ohms

Output:
The current is 3.0 amps.
