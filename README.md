# iz_time

Your learning projects, connected to [Project Episteme](https://github.com/razaele0003/Project_Episteme).

## Start here

1. Pick a brief below and create `main.py` in that project folder.
2. Build the solution yourself. Test it locally.
3. Create a `README.md` beside your solution with at least 40 words explaining inputs, outputs, your approach and edge cases.
4. Commit and push to `main`.
5. Open Project Episteme and select **Sync GitHub**. The dashboard displays exactly which source checks passed.

These starter folders contain briefs only, not completed exercises. Dashboard completion means the configured static checks passed. It does not establish correctness or mastery. Automatic push updates require the webhook deployment described in Project Episteme's README; until then use manual sync.
